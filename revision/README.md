# `revision/` — proposal-revision workflow

The files the manuscript-revision workflow in `CLAUDE.md` reads and writes.

| File | What it is |
|---|---|
| `RTC_DECISION_LETTER.md` | The official RTC comments, unedited (source of truth) |
| `REVISION_QUEUE.md` | Pending revision tasks |
| `TRACKER.md` | Change log |
| `AUDIT_TRAIL.md`, `AUDIT_TRAIL_READABLE.md` | Before/after log of manuscript edits (LaTeX and plain English) |
| `PROGRESS.md` | Revision progress as of 2026-08-24 |
| `CHANGE_REPORT_FROM_KHALIL_MARL_AND_RTC.md` | Changes relative to the original MARL repo |
| `Manuscript_Pre_Major_Revision.pdf` | The manuscript before the major revision |
| `Conformity_of_Revisions_TEMPLATE.pdf` | The blank conformity-of-revisions form |

The as-submitted revision is frozen in `submissions/2026-08-29_proposal-revision_AS-SUBMITTED/`.
